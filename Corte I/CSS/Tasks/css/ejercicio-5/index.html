Ejercicio 5 — Display

Elementos div

div con display: block
div con display: inline-block
div con display: none (no se ve)

Elementos span

span con display: inline span con display: block span con display: inline-block

Diferencias observadas

El elemento con display: block ocupa todo el ancho disponible y siempre empieza en una nueva línea, como se ve en el primer div.

El elemento con display: inline no inicia una nueva línea, se acomoda junto a otros elementos y no respeta el ancho ni el alto asignados, como se ve en el primer span.

El elemento con display: inline-block se comporta como inline (no rompe la línea) pero sí respeta el ancho, el alto y los márgenes, como se observa en el segundo div y en el tercer span.

El elemento con display: none desaparece completamente de la página: no ocupa espacio ni es visible, como sucede con el tercer div.
