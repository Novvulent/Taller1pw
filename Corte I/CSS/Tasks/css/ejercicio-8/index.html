Ejercicio 8 — Responsive Design

¿Qué es el diseño responsive?

El diseño responsive (o diseño web adaptable) es una técnica que permite que una página web se ajuste automáticamente al tamaño de la pantalla del dispositivo que la está mostrando, ya sea un computador de escritorio, una tableta o un teléfono móvil.

Escritorio

Ancho fijo de 700px, centrado en la pantalla.

Móvil

Ancho del 100%, con margen interno reducido.

Media Query

@media (max-width: 768px)
