Estudiantes desarrollan proyecto web innovador

Aplican CSS avanzado en su taller de la universidad

Durante la semana, los estudiantes del curso Programación en Ambiente Web I trabajaron en una serie de ejercicios prácticos enfocados en el diseño y la maquetación de páginas web utilizando hojas de estilo en cascada.

El objetivo principal de esta actividad fue reforzar los conceptos fundamentales de tipografía, permitiendo a los estudiantes experimentar con distintas fuentes, tamaños, pesos y alineaciones de texto.
