Taller de CSS

En este taller pondrás en práctica los conceptos fundamentales de CSS mediante diferentes ejercicios de diseño y presentación de páginas web.

Cada ejercicio debe desarrollarse utilizando un archivo HTML y una hoja de estilos CSS independiente.

Organización de la entrega

Cada ejercicio debe desarrollarse en su propia carpeta. Dentro de cada carpeta deben existir el archivo HTML y su respectiva hoja de estilos CSS.

  • css/
    • ejercicio-1/
      • index.html
      • styles.css
    • ejercicio-2/
      • index.html
      • styles.css
    • ...
    • ejercicio-10/
      • index.html
      • styles.css

Importante: cada ejercicio debe utilizar únicamente los archivos correspondientes a su propia carpeta.

Ejercicios

Ejercicio 1 — Selectores CSS

Aplicar diferentes tipos de selectores CSS para modificar la apariencia de los elementos de una página.

Requisitos

  • Crear un título principal.
  • Crear tres párrafos.
  • Utilizar un selector por etiqueta.
  • Utilizar un selector por clase.
  • Utilizar un selector por id.
  • Aplicar diferentes colores y tamaños de texto a los elementos.

Conceptos

  • Selector por etiqueta.
  • Selector por clase.
  • Selector por id.

Ejercicio 2 — Colores y fondos

Personalizar la apariencia visual de una página utilizando colores, fondos y dimensiones.

Requisitos

  • Crear tres cajas.
  • Asignar un color diferente a cada caja.
  • Agregar color al texto.
  • Definir un fondo para la página.
  • Definir el ancho de las cajas.
  • Definir el alto de las cajas.

Conceptos

  • color
  • background-color
  • width
  • height

Ejercicio 3 — Tipografía

Diseñar visualmente una noticia utilizando diferentes propiedades relacionadas con la tipografía.

Requisitos

  • Crear un título principal.
  • Crear un subtítulo.
  • Crear dos párrafos.
  • Definir una familia tipográfica.
  • Modificar el tamaño del texto.
  • Modificar el peso de la fuente.
  • Modificar la alineación.
  • Transformar el texto.

Conceptos

  • font-family
  • font-size
  • font-weight
  • text-align
  • text-transform

Ejercicio 4 — Box Model

Crear una tarjeta personal y aplicar el modelo de cajas de CSS.

Requisitos

  • Mostrar el nombre.
  • Mostrar la carrera.
  • Mostrar la ciudad.
  • Agregar un borde.
  • Definir un espacio interno.
  • Definir un espacio externo.
  • Definir ancho y alto.

Conceptos

  • border
  • padding
  • margin
  • width
  • height

Ejercicio 5 — Display

Comprender cómo CSS modifica el comportamiento y la distribución de los elementos mediante la propiedad display.

Requisitos

  • Crear tres elementos div.
  • Crear tres elementos span.
  • Realizar pruebas utilizando block.
  • Realizar pruebas utilizando inline.
  • Realizar pruebas utilizando inline-block.
  • Realizar pruebas utilizando none.
  • Explicar las diferencias observadas.

Concepto

Propiedad display.
